# DualClip

A lightweight Python desktop utility that extends the traditional system clipboard with two independent clipboard slots.

## Planned Features

- Maintain two independent clipboard entries.
- Detect consecutive `Ctrl+C` presses to manage clipboard slots.
- Detect consecutive `Ctrl+V` presses to paste from different slots.
- Run silently in the background.
- Preserve normal clipboard behavior.

## Technologies

- Python
- pynput
- pyperclip
